# Как проверить систему вручную

Проверяйте в этом порядке: сначала мини-CRM (workflow 1-2), потом Sales Engine
(workflow 3-4) — они используют одну и ту же таблицу и один и тот же Apps
Script URL/токен.

## 1. workflow-1-new-lead (заявка с сайта)

1. Импортируйте и активируйте workflow в n8n, подставьте свои значения вместо
   плейсхолдеров (см. `automation/README.md`).
2. Скопируйте Production URL ноды Webhook.
3. Отправьте тестовый запрос через терминал (замените `<PRODUCTION_URL>` на
   свой адрес):

   ```bash
   curl -X POST "<PRODUCTION_URL>" \
     -H "Content-Type: application/json" \
     -d @automation/test/sample-netlify-payload.json
   ```

   Файл `sample-netlify-payload.json` — пример без реальных данных.
4. Проверьте:
   - В Telegram пришло сообщение "🆕 Новая заявка...".
   - В таблице "TAINA — Воронка" появилась новая строка со Статусом "Новый".
5. Если хотите проверить ветку ошибки — временно впишите в ноду "Записать в
   Google Таблицу" неверный URL или токен, повторите curl-запрос и убедитесь,
   что пришло сообщение "⚠️ НЕ ЗАПИСАНО В ТАБЛИЦУ". Не забудьте вернуть
   правильные значения обратно.

## 2. workflow-2-reminders (напоминание)

Ждать реального дня без ответа не нужно — можно проверить сразу:

1. В таблице "TAINA — Воронка" вручную впишите тестовую строку: Статус =
   "Новый", Дата следующего действия = вчерашняя дата.
2. В n8n откройте workflow-2, нажмите "Execute Workflow" (запустить вручную)
   на ноде "Каждый день в 10:00" (или на всём workflow).
3. Проверьте, что в Telegram пришло сообщение "⏰ Заявки без ответа: N" со
   строкой про вашу тестовую заявку.
4. Уберите тестовую строку или отметьте её статус как "Отвечено"/другой не
   входящий в список — чтобы не путалась с реальными данными.

## 3. workflow-3-lead-finder (поиск лидов)

Проверяйте на 2–3 компаниях, чтобы не тратить лишний лимит Outscraper:

1. В ноде "Параметры поиска (меняйте здесь)" поставьте `limit = 2` или `3`.
2. **Сначала проверьте только вызов Outscraper отдельно**, ДО запуска всего
   workflow — это сэкономит лимит, если что-то настроено неверно:
   ```bash
   curl -G "https://api.app.outscraper.com/maps/search-v3" \
     -H "X-API-KEY: <ваш ключ>" \
     --data-urlencode "query=стоматология Москва" \
     --data-urlencode "limit=2" \
     --data-urlencode "async=false"
   ```
   Сравните URL/параметры с тем, что показано в вашем личном кабинете
   Outscraper (API docs) — я не смог свериться с этим эндпоинтом напрямую
   (см. предупреждение в самом workflow и в README), поэтому важно проверить
   именно у себя в аккаунте перед первым запуском на реальных данных.
3. Если curl вернул список компаний с полями вроде `name`, `site`,
   `category` — можно запускать сам workflow (кнопка "Запустить вручную" в
   n8n, на ноде "Запустить вручную").
4. Проверьте по шагам:
   - Пришли ли карточки лидов в Telegram с кнопками "Одобрить"/"Отклонить".
   - Появились ли новые строки в таблице со Статусом "На рассмотрении".
   - Если запускали дважды на одних и тех же компаниях — вторая попытка не
     должна создавать дубликаты (проверка "Проверить дубликат" должна их
     отсеять).
5. Если что-то падает — смотрите, от какой ноды пришло сообщение
   "⚠️ Ошибка в Sales Engine: ..." в Telegram, это подскажет, на каком шаге
   проблема.

## 4. workflow-4-approval-handler (кнопки Одобрить/Отклонить)

1. Активируйте workflow-4 в n8n (должен работать одновременно с workflow-3).
2. В Telegram нажмите "✅ Одобрить" на любой тестовой карточке лида.
3. Проверьте:
   - Сообщение в Telegram отредактировалось: кнопки исчезли, добавилась
     строка "✅ Одобрено".
   - В таблице у этой строки Статус изменился на "Одобрено".
4. Повторите с кнопкой "❌ Отклонить" на другой карточке — Статус должен
   стать "Отклонено".

## Общий чек-лист готовности

- [ ] Заявка с сайта → появляется в таблице → приходит в Telegram
- [ ] Просроченная заявка → напоминание в Telegram
- [ ] Поиск лидов → карточка в Telegram → строка в таблице
- [ ] Кнопка в Telegram → меняется статус в таблице и карточка в Telegram
- [ ] Повторный запуск поиска по тем же компаниям не создаёт дублей
